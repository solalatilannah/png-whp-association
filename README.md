# png-whp-association
HTML5 website for PNGUoT Western Highlands Province Student Association
## Project Theme
This project is a simple HTML5 website designed for the PNGUoT Western Highlands Province Student Association
It introduces the association, shares information about students' activities, and provides a contact/registration form

## Target Audience 
-PNGUoT students (especially those from Western Highlands Province)
-University staff and community members 
-Potential new members interested in joining the association

## Purpose 
This website aims to:
-Provide clear information about the associations' purpose and activities
-Share upcoming events and student support programs
-Allow students to register or contact the association through an accessible online form

## Sitemap/Pages
1. **Home Page (index.html)** - Welcome message and introduction
2. **Activities Page (info.html)** - Details of events, programs, and student support
3. **Contact Page (contact.html)** - Contact Details and Registration form

## Technologies used 
- HTML5 (semantic structure)
- Basic CSS for readability and presentation
- Git + GitHub for version control
- GitHub pages for publishing

## User Tasks 
- Navigate between pages using the menu
- Read about association activities
- Submit the registration/registration form

## Accessibility Features
- Sematic HTML structure ('header', 'nav', 'main', 'section', 'footer',)
- Logical heading hierarchy ('h1', 'h2', 'h3',)
- Images with 'alt' text
- Form with labels and validation attributes
